# 2026-09-10

## 白屏/黑屏（含底栏全部空白）问题修复

- **现象**：`app-debug.apk` 启动后整页空白（浅色白、深色黑），连底部导航栏都看不到。
- **根因**：运行时每帧抛 `Failed assertion: '!semantics.parentDataDirty'`（位于 `PipelineOwner.flushSemantics` → `RendererBinding.drawFrame`）。这是 Flutter 框架在语义(semantics)刷新阶段的 debug-only 断言。
- **触发点**：框架 `Badge` 组件（内部 Stack/Positioned + Semantics）在部分 Flutter 版本会留下 dirty parentData。项目中 `Badge` 用在 `console_shell_page.dart` 底栏「消息」图标（`_MessageIcon`）和 `message_page.dart` 客服条目，底栏那个每帧都在，故整页崩溃。
- **修复**：两处 `Badge` 都替换为手写 `Stack(clipBehavior: Clip.none)` + `Positioned` 红点（`DecoratedBox` 圆形）。`flutter analyze` 通过。
- **注意**：该断言仅 debug 模式抛；release 可能不崩但渲染仍有隐患。复现设备 Android 17 (API 37) 真实机。
- 规避经验：本项目不要在常驻子树里用 `Badge`；如需要红点用 Stack+Positioned 手写。

## 次级崩溃修复（同一调试会话）
- 真机运行日志还暴露第二个渲染崩溃：`BoxConstraints forces an infinite width`
  `FilledButton ticket_detail_page.dart:731`（实为 729 行 `SizedBox(height:48, child: FilledButton)` 无 width）。
- 该错只在打开工单详情页时触发（非首屏），是 `parentDataDirty` 的级联源之一。
- 修复：删除无宽度的 `SizedBox` 包裹，改由 `FilledButton.styleFrom(minimumSize: Size(72,48), maximumSize: Size.fromHeight(48))` 约束尺寸。
- 经验：Row 内的按钮不要用 `SizedBox(height: x, child: Button)`（无 width→无限宽）。需要定高用按钮 style 的 minimumSize/maximumSize。
- 注意：运行中途设备 24129PN74C（Android 17）断连，未能做最终真机复验；首屏已确认可进入控制台并轮询接口。

## 客服聊天气泡左右对齐 bug 修复
- 现象：在线客服页里“我的消息”和“客服消息”都贴在最左边（应为客服左、我右）。
- 数据正确：实测 `/v1/chat/list` 返回 `is_admin` 0/1 混合（0=自己 uid=6，1=客服），`fromAdmin => isAdmin==1` 解析无误。
- 真因：气泡用 `Flexible → Column(crossAxisAlignment: end)`，`Column` 在 Flexible 内收缩到内容宽度，end/start 对齐无空间可移，全部贴左。
- 修复：`Flexible` 内给 `Column` 外包 `SizedBox(width: double.infinity)` 占满整行，左右对齐生效。`lib/features/support/widgets/chat_bubble.dart`。
- 经验：Flutter 中想让 Column 子项按左右对齐，必须保证 Column 宽度大于内容（SizedBox.expand/width:infinity 或 Align 包一层），否则 crossAxisAlignment 不生效。
